🏠 House Price Prediction

Project Report  ·  Python ML Project  ·  Linear Regression

Overview

A full-stack machine learning application that predicts house prices from area (sq ft) and number of rooms. The project ships a Streamlit interactive frontend for data exploration and prediction, plus a Flask REST API backend for programmatic access.

How to Run

  • 1
    Install dependencies
    pip install -r house_price_prediction/requirements.txt
  • 2
    Train the model
    python house_price_prediction/train_model.py
  • 3A
    Launch Streamlit frontend
    streamlit run house_price_prediction/app.py → http://localhost:8501
  • 3B
    Launch Flask API
    python house_price_prediction/api.py → http://127.0.0.1:5000
